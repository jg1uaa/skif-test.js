# skif-test.js

## Description

Morse decoder for practice use, with [SKIF](https://github.com/jg1uaa/skif-arduino) (simple key interface), DTR/DSR line and HID (Keyboard/Mouse).

## Usage

Invoke js/main.js from index.html. To use SKIF or DTR/DSR line, WebSerial capable browser/server required.

## Description of status display

See [README.md of skif-test](https://github.com/jg1uaa/skif-test/blob/master/README.md).

## Note

Currently SKIF support is not implemented.
